A small Python program that writes the funniest one line a talking elevator could say, to /output/entry.txt. The line is fixed and deterministic — the same 102-character line every run: the elevator knows its regular's weight and floor, and that he lied about both on his dating profile.

## Run it

```sh
python3 main.py
```
